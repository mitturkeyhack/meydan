# Meydan ☾

Türk mahalle kültüründen kahramanlarla 1v1 online arena oyunu.

- **Kahramanlar:** Çaycı Abi, Simitçi, Keloğlan, Pazarcı Teyze (yakında: Nasreddin Hoca, Kangallı Çoban, Dolmuşçu, Ozan)
- **Mod:** Düello (3 rauntta 2 alan kazanır) · **Harita:** Kapalıçarşı
- **Online:** Supabase Realtime (hızlı eşleşme + arkadaş odası), kupa ve sıralama veritabanında
- **Antrenman:** internetsiz bota karşı

## APK
GitHub'a gönderdiğin her değişiklikte **Actions → Meydan APK** çalışır, bitince
**Artifacts** bölümünden `Meydan-APK` indirilir.

## Geliştirme
```
npm install
npm run dev
```
Masaüstünde: WASD yürü, sol tık saldırı, E veya sağ tık GAZ (süper).
